# Washwashni

آلة حاسبة فضائية كوميدية لأندرويد (Android 9+ / API 28+). Java خالصة بدون مكتبات خارجية: كل الرسومات بـ Canvas وكل الأصوات مولَّدة برمجياً (لا ملفات صوتية ولا صور).

## الميزات
- شكل بكسل كامل: خط بكسل، أزرار بحواف مدرّجة، شاشة LCD، وخلفية سماء فارغة مع نجوم قليلة بعيدة.
- شخصية صغيرة (مرسومة بالبكسل من الصورة) تمشي وتقفز بين صفوف الأزرار وتقفز عند كل ضغطة.
- حساب صحيح مع أولوية الضرب والقسمة (`Calc.java` + اختبارات JUnit).
- **3 عمليات أو أكثر + "="** ← مشهد "ELIMINATED!" بملء الشاشة (~2.8 ثانية) ثم تظهر النتيجة.
- **زر C** ← الأرقام تتحول لكائنات صغيرة، تفزع، ثم **تُقطع فعلياً إلى نصفين** (نصف علوي ونصف سفلي) مع لون أحمر وعظمة بيضاء، وتسقط وتتلاشى مع دخان وشرارات.
- صوت: أصوات كيبورد ميكانيكي لكل ضغطة (مولَّدة برمجياً)، موسيقى هادئة، وزر لكتم الصوت والتحكم بالمستوى.
- الأيقونة هي صورة الشخصية، واسم التطبيق Washwashni.

## البناء
الأسهل: GitHub Actions يبني الـ APK تلقائياً مع كل push. ادخل تبويب **Actions** ← آخر تشغيل ← **Artifacts** وحمّل `W-SPACE-CALCULATOR-release` ثم ثبّته.

محلياً (يحتاج Android SDK وGradle 8.7+ وJDK 17):
```
gradle :app:testDebugUnitTest
gradle :app:assembleDebug     # app/build/outputs/apk/debug/
```
