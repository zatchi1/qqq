# Washwashni

آلة حاسبة فضائية كوميدية لأندرويد (Android 9+ / API 28+). Java خالصة بدون مكتبات خارجية: الرسومات بـ Canvas، والمشاهد السينمائية تستخدم الصور والأصوات المرفوعة (`design/` للأصول الأصلية، و`tools/make_assets.py` يعيد توليد `res/`).

## الميزات
- شكل بكسل كامل: خط بكسل، أزرار بحواف مدرّجة، شاشة LCD، وخلفية سماء فارغة مع نجوم قليلة بعيدة.
- شخصية صغيرة (مرسومة بالبكسل من الصورة) تمشي وتقفز بين صفوف الأزرار وتقفز عند كل ضغطة.
- حساب صحيح مع أولوية الضرب والقسمة (`Calc.java` + اختبارات JUnit).
- **3 عمليات أو أكثر + "="** ← مشهد من 3 مراحل متزامن مع الصوت: (1) الشخصية الطافية + صوت T R R R وكتابة العبارة حرفاً بحرف مع نبضات الصوت، (2) النتيجة الحقيقية بخط مضيء، (3) صورة الشخصية المقطوعة تنفصل مع صوت KILL لحظة الضربة. اللمس يتخطى المشهد.
- **زر C** ← الأرقام تتحول لكائنات صغيرة وتُقطع إلى نصفين وتسقط، والقطع يتزامن مع ضربة صوت KILL.
- **الرقم 106** (كتابةً أو كنتيجة) ← بعد ثانيتين يُشغَّل صوت 106 (يُلغى إذا تغيّرت الشاشة، ولا يتكرر).
- صوت الضغط على الأزرار مقتطع من T R R R، مع تأثير بصري صغير عند كل ضغطة.
- الأيقونة هي صورة الشخصية، واسم التطبيق Washwashni.

## البناء
الأسهل: GitHub Actions يبني الـ APK تلقائياً مع كل push. ادخل تبويب **Actions** ← آخر تشغيل ← **Artifacts** وحمّل `W-SPACE-CALCULATOR-release` ثم ثبّته.

محلياً (يحتاج Android SDK وGradle 8.7+ وJDK 17):
```
gradle :app:testDebugUnitTest
gradle :app:assembleDebug     # app/build/outputs/apk/debug/
```
