# W-SPACE CALCULATOR

آلة حاسبة فضائية كوميدية لأندرويد (Android 9+ / API 28+). Java خالصة بدون مكتبات خارجية: كل الرسومات بـ Canvas وكل الأصوات مولَّدة برمجياً (لا ملفات صوتية ولا صور).

## الميزات
- شخصية فضائية خضراء ثلاثية الأبعاد (تدرجات وإضاءة وانعكاسات) تطفو فوق الحاسبة، مع كائنات صغيرة تمر في الخلفية.
- خلفية فضاء: نجوم، كواكب، كويكبات، سفن، انفجارات، شرارات ودخان.
- أزرار زجاجية متوهجة، شاشة مستقبلية، كل رقم يظهر بأنميشن "pop".
- حساب صحيح مع أولوية الضرب والقسمة (`Calc.java` + اختبارات JUnit).
- **3 عمليات أو أكثر + "="** ← مشهد "ELIMINATED!" بملء الشاشة (~2.8 ثانية) ثم تظهر النتيجة.
- **زر C** ← الأرقام تتحول لكائنات فضائية، تفزع، ثم **تُقطع فعلياً إلى نصفين** (نصف علوي ونصف سفلي كصورتين منفصلتين) مع لون أحمر وعظمة بيضاء صغيرة، وتسقط وتتلاشى مع دخان وشرارات، وتبقى الشاشة فارغة.
- صوت: نقرات، مؤثرات للعمليات، صوت الإقصاء، موسيقى إلكترونية بباص قوي، وزر لكتم الصوت والتحكم بمستوى الموسيقى والمؤثرات (أيقونة السماعة أعلى اليمين).

## البناء
الأسهل: GitHub Actions يبني الـ APK تلقائياً مع كل push. ادخل تبويب **Actions** ← آخر تشغيل ← **Artifacts** وحمّل `W-SPACE-CALCULATOR-release` ثم ثبّته.

محلياً (يحتاج Android SDK وGradle 8.7+ وJDK 17):
```
gradle :app:testDebugUnitTest
gradle :app:assembleDebug     # app/build/outputs/apk/debug/
```
